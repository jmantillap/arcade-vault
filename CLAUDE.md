## Project state

"ARCADE VAULT": retro arcade game portal (play online, compete for high scores). Currently only the untouched `create-next-app` scaffold (`app/page.tsx` is the default Next.js landing). The product spec is `references/prompt-arcade-vault.md` — read it before building features. Key points from it:

- **All UI text in Spanish** (e.g. "JUGAR", "VOLVER AL VAULT", "Salón de la Fama", "PUNTUACIÓN GUARDADA").
- Dark neon theme: bg `#0a0a0f`, cyan `#00f5ff`, magenta `#ff006e`, yellow `#f5ff00`; fonts "Press Start 2P" (headings) + "Courier Prime" (body); scanlines + animated perspective grid + CRT glow.
- Screens: library (search/filter + game cards), game detail (top-10 leaderboard), player (external HTML game in sandboxed iframe inside a CRT bezel, HUD, pause/exit, game-over modal), auth (login/register/guest/social), Hall of Fame (per-game tabs, top 10, gold/silver/bronze).
- Guest scores in `localStorage`; mark where a real backend (REST / Supabase) would plug in for authenticated users.

README says the workflow is spec-driven (`/spec`, `/spec-impl` skills from `Klerith/fernando-skills`).

## Next.js version caveat

`next` 16.4.0 / `react` 19.3.0 — newer than typical training data. `AGENTS.md` requires reading the relevant guide in `node_modules/next/dist/docs/` (`01-app`, `02-pages`, `03-architecture`, `04-community`, `index.md`) before writing Next.js code, and heeding deprecation notices.

`next.config.ts` enables non-default features that affect how pages must be written:
- `cacheComponents: true` and `partialPrefetching: true` (Cache Components model — check the docs for dynamic data / `use cache` rules before fetching in components).
- `experimental.agentFeedback: true`.
- Turbopack with an explicit `@tailwindcss/turbopack` loader rule for `*.css` (Tailwind v4, configured via `@import "tailwindcss"` and `@theme inline` in `app/globals.css`, no `tailwind.config`).

## Conventions in the scaffold

- App Router only (`app/`); path alias `@/*` → repo root.
- `RootLayout` uses the globally available `LayoutProps<"/">` type (generated by Next, no import needed). Fonts are loaded via `next/font/google` and exposed as `--font-geist-sans` / `--font-geist-mono` CSS vars mapped in `@theme inline`; the spec's Press Start 2P / Courier Prime should be wired the same way.
- Theme colors are CSS vars (`--background`, `--foreground`) in `globals.css` with a `prefers-color-scheme` dark override; layout/metadata still contain scaffold defaults (`lang="en"`, "Create Next App") to be replaced (should be `es`).
